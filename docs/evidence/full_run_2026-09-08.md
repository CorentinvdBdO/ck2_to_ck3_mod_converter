## The three findings this run produced that are not converter bugs

1. **8 same-sex `add_spouse` pairs.** CK3 1.19 has no same-gender marriage;
   `add_spouse` between two characters of one gender is `error(wrong-gender)`
   and the line is ignored. CK2 allowed it and Faerûn flags them itself with
   `Audax Validator "." Ignore_NEXT`. Now reported as the integrity class
   `same-sex spouse` (`docs/evidence/characters_integrity.csv`) instead of
   being emitted silently.
2. **75 `add_character_modifier` values with no CK3 modifier.** They name
   Faerûn's own `common/event_modifiers`, and no step converts that folder, so
   the lines are commented out rather than left dangling.
3. **1 holy site on a dead county** (`laduguer -> c_barakuir`). The `map` step
   places no barony in `c_barakuir`, so `titles` drops the county.
